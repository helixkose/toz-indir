# TÖZ

Sade ve hızlı tablo uygulaması. Excel, LibreOffice ve CSV dosyalarıyla çalışır.

## İndir

| | |
|---|---|
| **Windows** | [TOZ-Windows-Kurulum.exe](../../releases/latest/download/TOZ-Windows-Kurulum.exe) |
| **Android** | [TOZ-Android.apk](../../releases/latest/download/TOZ-Android.apk) |

Tüm sürümler ve değişiklikler: [Sürümler](../../releases)

## Kurulum

**Windows:** Kurulum dosyasını aç. “Windows kişisel bilgisayarınızı korudu” uyarısı çıkarsa **Ek bilgi → Yine de çalıştır**. TÖZ bundan sonra kendini otomatik günceller.

**Android:** APK'yı telefonda aç. “Bilinmeyen uygulamalar” uyarısı çıkarsa **Ayarlar → Bu kaynaktan izin ver → Yükle**. TÖZ bundan sonra kendini otomatik günceller.

TÖZ şu an ücretsiz beta sürümündedir.
